# The Gear : The Puzzler — Gear Workshop

LÖVE2D / Lua 게임. 
움직이는 초록 동력원에서 황금 톱니바퀴까지 톱니바퀴를 배치해 동력을 전달하는 구조.

## 진행
1. 왼쪽 TOOLBOX에서 작은/중간/큰 톱니바퀴를 왼쪽 마우스로 끌어 게임 존에 놓습니다.
2. 가까이 놓으면 톱니바퀴의 가장자리가 맞닿도록 자동으로 위치가 보정됩니다.
3. 초록 동력원과 연결된 톱니바퀴는 자동으로 회전합니다. 끊어진 톱니바퀴는 멈춥니다.
4. 황금 GOAL 기어까지 연결되면 오른쪽 벨트와 도르레가 움직이고 우물 속 상자가 올라옵니다.
5. 완전히 올라온 닫힌 상자를 클릭하면 뚜껑이 열립니다.
6. 상자 안 열쇠를 클릭한 다음 오른쪽 DOOR를 클릭합니다.
7. SPACE로 다음 스테이지에 진입합니다. 5단계 완료 후 ENTER로 처음부터 다시 시작합니다.

## 조작 및 배치 규칙
- 왼쪽 드래그: 보관함 기어 꺼내기 / 이미 배치한 기어 이동.
- 오른쪽 클릭: 배치한 기어를 보관함으로 돌려놓기.
- 보관함에 드래그해서 놓아도 기어를 반환할 수 있습니다.
- 빨간 테두리: 배치 불가 / 초록 테두리: 배치 가능.
- 겹치거나 게임 존을 벗어난 곳에 놓으면 새 기어는 보관함으로, 이동 중인 기어는 원래 위치로 돌아갑니다.
- 동력원과 황금 기어의 위치는 고정입니다. 기어 수량은 스테이지별로 지정되며 다음 단계에서 초기화됩니다.
- 기어는 빈 공간에도 놓을 수 있습니다. 동력원까지 연결되어야 움직입니다.
- 홀수 개의 기어로 닫힌 고리를 만들면 회전 방향이 충돌하므로 해당 동력망이 정지합니다.
- H: 각 기어의 크기와 배치 순서를 보여주는 원형 힌트. 숫자 순서대로 보관함에서 기어를 배치하면 됩니다.
- R: 현재 스테이지 초기화 / M: 음소거 / ESC: 드래그 취소, 드래그 중이 아니면 종료.
- 창을 다른 곳으로 전환하면 진행 중인 드래그를 취소합니다.

**도르레**
- 양방향 회전을 인양 방향으로 변환하는 게임 규칙을 사용
- 연결을 끊으면 인양이 멈추고, 이미 올라온 높이는 유지됩니다(역회전 방지 장치).
- 인양이 완료되면 조립과 회전을 멈추고 상자 클릭을 기다립니다.
